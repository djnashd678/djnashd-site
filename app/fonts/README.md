# Bundled website fonts

Inter and Space Grotesk are loaded with `next/font/local` so production builds do not depend on Google Fonts CSS responses or font downloads. The Latin variable WOFF2 files are byte-for-byte identical to the fonts in the approved October preview. Existing CSS variables, normal styles, `display: swap`, and used weight ranges are retained.

Official Google Fonts sources retrieved 2 October 2026:

- Inter v20 (weights 400–800): https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7W0Q5nw.woff2
- Space Grotesk v22 (weights 500–700): https://fonts.gstatic.com/s/spacegrotesk/v22/V8mDoQDjQSkFtoMM3T6r8E7mPbF4C_k3HqU.woff2
