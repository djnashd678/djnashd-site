# DJNASHD.com

## Run locally
npm install
npm run dev

## Publish
1. Create an empty GitHub repo named `djnashd-site`
2. Upload these files
3. Import the repo into Vercel
4. Add `djnashd.com` in Vercel Project Settings → Domains

## Edit events
Update `data/events.ts`.
